## 二、修复的两个 bug（重点看）

### Bug 1：子应用挂载不上（白屏、无任何报错）

- **现象**：点菜单 tab 标签出来了，但内容区空白，F12 无任何报错。
- **根因**：`packages/tab-manager/src/TabManager.ts` 的 `mountTab` 有一道幂等守卫 `if (record.status === 'loading' || 'loaded') return;`，而 `getOrCreateRecord` 新建记录时初始状态恰好也是 `'loading'` —— 首次挂载被自己拦掉，`startApp` 一次都没执行。
- **修复**：新建记录初始状态改为 `'idle'`（`types.ts` 的 `InstanceStatus` 新增 `'idle'`）。
- **定位手段**：无头 Chrome + 原生 CDP 抓网络，发现「发往子应用端口的请求数为 0」→ 锁定 `startApp` 没被调用。

### Bug 2：明暗主题切换，子应用不跟着变

- **现象**：主应用背景/文字变了，子应用看起来没变（实际是文字变白、背景还白 → 白字白底）。
- **根因**：`packages/ui-theme/src/theme.css` 用了 `:root` / `:root[data-ix-color-schema='dark']` 写深色覆盖。**在无界 shadow DOM 里，`:root` 匹配的是 shadow host（`<wujie-app>`），不是子应用的 `<html>`**，所以深色背景覆盖这条规则作用不到子应用。而 iX 自己的 token 用的是纯属性选择器 `[data-ix-theme=classic][data-ix-color-schema=dark]`，能匹配到，所以文字色变了、背景色没变。
- **修复**：`--brand-*` 别名选择器从 `:root` 改成 `[data-ix-theme='classic']`（与 iX token 选择器保持一致）。
- **定位手段**：无头 Chrome 抓 computed style，发现 `--brand-bg` 始终 `#ffffff`、而 `--theme-color-std-text` 变了。
